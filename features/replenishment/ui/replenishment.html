Coverage target
ABC ranks each SKU by how much it sells: A the fast movers, B the middle, C the slow tail. Ticking this asks for more cover on the fast ones and less on the slow ones — A = 10 weeks · B = 8 · C = 6 — instead of the single window above. It comes off by default: those steps were set when the average was one imported column, and with a sales window you can choose the plain cover is easier to explain. Turn it on if you want the fast movers carried deeper than the tail.
